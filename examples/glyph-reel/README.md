# glyph-reel

The movy **v0.4.0** showcase: a ~40 second timeline that puts the new
**GlyphLayer** in front of a living **Frame** scene, and records itself with
the new **VideoExport**. All text is glyphs over half-block pixels, so the
field's colors and glow show through behind every character.

```sh
zig build run-glyph-reel                 # loops (ESC / q quits)
zig build run-glyph-reel -- once         # play once from black, hold the closing card
zig build run-glyph-reel -- wide         # 120x20 cells (3:1 banner) instead of 100x28 (16:9)
zig build run-glyph-reel -- pal ember    # palettes: aurora (default), decrypt, ember
zig build run-glyph-reel -- shot 15.8 out.ans   # headless frame at 15.8s
tools/ansi2html.py out.ans out.html --png out.png
```

Options combine, e.g. `-- once wide pal decrypt`.

> Needs a terminal of at least **100x28 cells** (or **120x20** with `wide`). It
> centers itself in whatever terminal size you have.

## Make the video

The reel records itself with `movy.VideoExport`: no terminal, no screen
capture, frame N rendered at exactly t = N / 60.

```sh
zig build -Doptimize=ReleaseFast
zig-out/bin/glyph-reel export                    # ~2370 PNGs, 1900x1064 -> export/  (~1 min)
tools/makevideo.sh export glyph-reel.mp4         # -> 1920x1080 @ 60fps H.264
tools/makevideo.sh export glyph-reel.mp4 --audio music.wav   # with a sound track
```

`export` plays the story once and holds the closing card for 2s (39.5s).
Export options combine with the others: `export full` renders exactly one
loop (40s), `small` uses 10x20 px cells (1000x560), `font dejavu` uses DejaVu
Sans Mono instead of JetBrains Mono, and `wide` / `pal <name>` work as live.
Frame 0 is t = 0, so a sound track that starts at 0 lines up with the
timeline below.

## Timeline

Everything is keyed to seconds (constants at the top of `main.zig`), so you
can line up sound with the beats in your editor.

| time (s)    | what happens |
|-------------|--------------|
| 0.0 - 1.2   | the field fades in from black |
| 1.0 - 6.0   | the scanner beam sweeps; the v0.4.0 news decrypts behind it |
| 8.6 - 11.0  | the news scrambles off, char by char |
| 10.2 - 12.8 | the movy logo rises from below the frame, transparent to white |
| 12.4 - 13.4 | the `.solid` bar fades in under the logo |
| 14.0        | the storm starts building |
| **15.6**    | **storm peak: flash, screen shake, shockwave rings** |
| 16.8 - 19.4 | the storm calms down |
| 19.4 - 21.6 | bar fades, logo drifts up and out |
| 21.0        | `● REC` + timecode appear |
| 21.4 - 25.0 | a pink beam sweeps right to left; VideoExport decrypts behind it |
| 27.4 - 29.0 | ...and scrambles off, REC goes away |
| 28.6 - 30.4 | the v0.3.0 recap decrypts in place (no beam) |
| 33.0 - 34.6 | ...and scrambles off |
| 35.0 - 36.0 | closing card decrypts in (`once` / `export` hold it from 37.5) |
| 38.0 - 40.0 | card scrambles off, fade to black, loop |

## How it's built

- **Background:** a few overlapping low-frequency sine waves blended through a
  three-stop palette (`fieldK()` / `fieldColor()`), drawn into the Frame's
  solid layer. The field runs on its own clock `tw`, which speeds up during the
  storm while the waves get denser, more warped, and gain a ripple running out
  from the logo. The palette cross-fades to its "hot" stops at the same time.
- **Text blocks** (`drawBlock()`): every character scrambles, locks in with a
  white flash (plus a `gcell()` glow burst), holds, then scrambles off at a
  random time. The news and VideoExport blocks lock where their beam passes,
  the recap and the card lock in random order. A line with a `bg` decrypts
  into a `.solid` bar.
- **The logo** is the 61x18 grayscale movy bitmap (`logo.zig`), blended over the
  field with an eased position and alpha. Its interior stays transparent, so
  the field shows through (dimmed during the storm to keep it readable).
- **The bar** under the logo is `.solid` glyphs whose background cross-fades
  from the pixels underneath (`cellUnder()`) to pink - a `.solid` fade-in.
- **The glyph storm** (`drawStormGlyphs()`): wherever the field crests, cells
  sparkle with scramble characters in the field's own brightened colors - text
  generated by the scene itself. `glyphGlow()` gives all of it a bloom halo.
- **The recording** (`exportFrames()`): the same `frameStep()` as live, driven
  by `VideoExport.time()` instead of the wall clock, then `writeFrame()`.

## Recording live instead

- Use `once`: it starts from black and holds the closing card at the end, so
  you get clean in and out points.
- Size the terminal to exactly 100x28 (or 120x20 with `wide`).
